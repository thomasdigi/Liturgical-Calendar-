          Subscribe Download

          iPhone: tap Subscribe, then confirm in the Calendar app. Android (Google Calendar): tap Copy link; then, on a computer, open calendar.google.com → Other calendars + → From URL, and paste it. A subscribed calendar updates itself as new months are added; a downloaded one doesn't.

          Print

          Prints the Mass or Hour on screen, with the day's heading, in the languages and layout you've chosen, without the buttons.

          E-book (EPUB)

          Makes a book for an e-reader (Kindle, Kobo, Apple Books, Google Play Books…) in the languages, calendar and version you've chosen. Each day is a chapter.

          Report a mistake

          A wrong text, a missing feast, something that doesn't work? The report is filled in with the day and settings on screen; just add what's wrong.

          Email a report Report on GitHub

          GitHub needs a free account; its list of reports is public, so you can follow when a mistake is fixed.
